## Setup Instructions

1. **Clone the repository**

   ```sh
   git clone <repository-url>
   cd <repository-directory>
   ```

2. **Set up environment variables**

   ```sh
   cp .env.example .env
   ```

3. **Install dependencies**

   ```sh
   npm install
   ```

4. **Run the development server**

   ```sh
   npm run dev
   ```
